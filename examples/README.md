# Example configurations

Copy any of these over `config/widgets.ini`, or point the app at one directly:

```
LiteWidgets.exe --config examples\analog.ini
```

| File | What it shows |
| --- | --- |
| [`minimal.ini`](minimal.ini) | A single clock with no panel — just text on the wallpaper |
| [`analog.ini`](analog.ini) | Analog dials, including a sweeping second hand |
| [`showcase.ini`](showcase.ini) | Gradients, glow, outlines, tracking and custom patterns |
| [`multi-monitor.ini`](multi-monitor.ini) | Anchored widgets across two displays |
| [`dashboard.ini`](dashboard.ini) | Several readings sharing one gauge, plus a month view, as a status panel |
